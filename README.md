# Rupa Vadlamudi — Portfolio v3

Modern responsive portfolio for an aspiring Data Scientist.

### Included
- Round professional profile photo crop
- Animated section headings that reveal on scroll
- Professional project visuals in square cards
- Data Science, Data Analytics and Machine Learning positioning
- GitHub, LinkedIn, resume placeholder, contact and certification cards

### Add later
- Put `resume.pdf` beside `index.html`.
- Replace `profile.jpg` with another photo using the same filename.
- Replace the five certificate-card links in `index.html` with your certificate file/page links.

### Free hosting
Upload these files to a GitHub repository and enable GitHub Pages.
